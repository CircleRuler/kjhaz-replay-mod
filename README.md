# 金庸群侠传X 剧情回放 MOD

给《金庸群侠传X》加一个**剧情回放**界面：像 galgame 的「场景回放」一样，把游戏里**全部剧情**列出来，搜索、翻页、点一下就跳过去看。

## 为什么需要它

游戏自带的控制台只能敲 `story 剧情key` 跳转，但：

- 剧情 key 得自己记、自己复制粘贴，很麻烦；
- 网上流传的剧情指令清单和现在的游戏对不上。

拿流传最广的那份清单实测，和游戏内存里的实际数据比对：

| 项目 | 数量 | 说明 |
| --- | --- | --- |
| 游戏里实际有的剧情 | **5950** | 从 `ResourceManager.GetAll<Story>()` 直接读出来 |
| 清单里的条目 | 4226 | |
| 其中游戏里**已经不存在**的 | 961 | 改名了或者删了，照着敲会报「指令有误」 |
| 清单里真正能用的 | **3265** | 只覆盖 54.9% |
| **游戏有、清单完全没有的** | **2685** | 占 45.1%，这些你永远搜不到 |

校验：3265（有效）+ 2685（缺失）= 5950。

所以不是「清单少了一点」，是清单里有近四分之一是废条目，同时漏掉了将近一半的剧情——这正是「很多角色、很多支线明明知道有却找不到」的原因。

本 MOD 直接从游戏内存里读取全部剧情，不依赖任何外部清单，MOD 更新后自动同步。

## 效果

- **5950 条**剧情全部列出（直接从游戏内存读，不依赖外部清单）
- **每页 48 条**（3 列 × 16 行），面板占屏幕 96%
- 支持关键词搜索（中文直接搜角色名/地名，走游戏原生输入框）
- 底部 **30 个页码**快捷跳页，当前页金色高亮
- **「只看CG」筛选**：一键筛出所有调用过 CG 图片的事件（约 440 条），把 5950 条里大量无意义的事件过滤掉
- 点条目**直接跳转**到该剧情并开始播放
- 点 `×` 关闭，回到游戏

> CG 筛选的原理：CG 是两级引用 —— `Scripts/resource.xml` 里定义 `key="场景.xxx" value="CGs/文件名"`，剧情脚本用 `BACKGROUND` 类型的 action 引用这个 key。所以扫描所有 story 的 actions，把 value 命中 CG 资源的挑出来即可。
>
> 注意 `StoryAction.type` 是**大写枚举**（`DIALOG` / `BATTLE` / `BACKGROUND` …），没有 `PICTURE` 类型；CG 实际是切背景实现的。另外 `LuaTool.CreateLuaTable` 返回的不是数组，遍历必须用 `pairs`（用 `ipairs` 一个都取不到）。
>
> `Movies/` 目录里的影片**不在剧情里**，是 `DialogUI` 里点击触发的独立面板（`PhotoPanelUI.Show2`），所以没有做影片筛选。

## 安装

需要 Python 3。

**方式一（推荐）**：把 `install.py` 复制到游戏根目录 —— 就是有 `金庸群侠传X.exe` 的那层文件夹 —— 然后在那个目录里执行：

```
python install.py
```

脚本会自动识别当前目录，不用填路径。

**方式二**：在任意位置指定游戏根目录：

```
python install.py "你的游戏根目录"
```

> 路径按你自己电脑上的实际位置填，比如 `D:\Games\金庸群侠传X`。
> 路径里有括号或空格时，要用英文双引号包起来。

脚本会自动：
1. 复制 `lua/replay.lua`、`lua/replay_main.lua` 到 MOD 的 lua 目录
2. 在 `main.lua` 的 `ROOT_getLuaFiles` 里注册
3. 在 `GameEngine.lua` 的 `GameEngine_jianghuContent` 里插入呼出入口
4. **自动配置 hosts**（见下）

可重复运行，不会重复插入。**换 MOD / MOD 更新后重跑一次即可。**

### 关于 hosts

这个 MOD 版游戏启动时会去连 `rz.protect-file.com` 做授权校验，连不上才会走离线分支——所以原版整合包要求你手动改 hosts。脚本会替你处理这条规则：

```
127.0.0.1 rz.protect-file.com
```

因为改 hosts 需要管理员权限，**脚本会弹一次 UAC 提权**（点「是」即可）。已经配置过的话会自动跳过，不会重复写入。原 hosts 会备份成 `hosts.kjhaz_bak`。

不想让脚本动 hosts 的话，在 UAC 弹窗点「否」，安装照常完成，但你需要自己加这条规则，否则进不了 MOD。

## 使用

1. 启动游戏，进入存档
2. 点**左上角主角头像**，打开「江湖」面板
3. 点面板顶部的**「江湖历练」标签**（默认就在这一页，再点一次即可）
4. 剧情回放界面弹出，搜索或翻页找到想看的剧情，点一下

> 只有点「江湖历练」标签才会呼出，点头像打开面板不会——这样不会每次看属性都弹一遍。

> 为什么挂在「江湖」面板上：这个引擎的 Lua 只有几个固定入口（`ROOT_*`、`GameEngine_*`），没有键盘/每帧钩子，也没有可用的控制台扩展点（`GameEngine_extendConsole` 在本引擎里不会被调用）。「江湖」面板是唯一由玩家主动触发、且确认会回调 Lua 的地方，所以把它当作入口。
>
> 头像和标签都会触发同一个回调（`GameEngine_jianghuContent`），传参也完全相同，没法从参数区分。所以用鼠标坐标判断：点标签时鼠标落在面板顶部偏左的区域，点头像时鼠标停在最左侧头像上，两者不会重叠。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `lua/replay.lua` | 入口层：算 MOD 路径、热重载业务模块 |
| `lua/replay_main.lua` | 业务层：读剧情库、建 UI、搜索、跳转 |
| `replay_catalog.txt` | 剧情缓存（5950 条剧情名），首次运行生成在**游戏根目录** |
| `replay_cg_index.txt` | CG 事件索引，每行「剧情名<TAB>CGs/xxx,CGs/yyy」，首次点「只看CG」时生成在**游戏根目录** |
| `replay_movie_index.txt` | 影片事件索引（哪些剧情播过 Movies 里的影片） |
| `install.py` | 安装脚本 |

运行时会在**游戏根目录**（有 `金庸群侠传X.exe` 的那层）生成三个缓存文件：

- `replay_catalog.txt` —— 剧情名缓存
- `replay_cg_index.txt` —— CG 事件 + 引用的具体文件名
- `replay_movie_index.txt` —— 影片事件

删掉任何一个都会自动重建（CG/影片索引重建约 0.4 秒）。

## 调参

`lua/replay_main.lua` 里几处常用参数：

- `local COLS, ROWS = 16, 3` —— 每页列数 / 行数（改这里就改了每页条数）
- `root.transform.localScale = Vector3(0.47, 0.47, 1)` —— 界面整体缩放

UI 尺寸按 2452×1321 的渲染分辨率标定。换分辨率后如果界面过大或过小，调 `localScale` 那个 0.47（数值越大界面越大）。

把 `DEBUG_TRACE` 改成 `true` 可以把运行过程写进 `replay_trace.log`，排查问题时用。

## 已知限制

- **hosts 那条规则没法写进游戏文件里**：域名 `rz.protect-file.com` 在游戏目录的任何文件里都搜不到明文（`Assembly-CSharp.dll`、lua 脚本、资源全查过了），说明是 native 层动态拼接或加密的，没有可替换的字符串。所以只能走系统级 DNS 重定向，做成安装时自动配置。
- 跳转时会强制关闭地图上的若干面板（人物 / 队伍 / 背包等），这是为了让剧情不被遮挡。跳完剧情会正常回到地图。
- 剧情是从「当前存档」的状态开始播的，所以有些剧情会因为缺少前置条件而表现异常（比如直接跳过、或对话内容不全）。这是剧情本身的依赖，不是 MOD 的问题。
